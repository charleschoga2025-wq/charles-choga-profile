CHARLES CHOGA PERSONAL PROFILE WEBSITE
=======================================

FILES
- index.html: complete responsive profile website, SEO metadata and Person JSON-LD.
- sitemap.xml: sitemap template.
- robots.txt: crawler instructions template.

PRIVACY CHOICES
This version intentionally does NOT publish:
- date of birth
- exact neighbourhood / residential location
- school name
- personal email or phone number

You are under 18, so keep those details private. "Harare, Zimbabwe" is sufficient for a public location description. Do not add a home address, daily routine, or private contact details.

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Replace every occurrence of https://YOUR-DOMAIN.example/ with your actual published website URL.
3. In the JSON-LD sameAs array, add only genuine public profile URLs that you control. Example:
   "sameAs": ["https://github.com/your-username"]
4. If you have a public profile photo, add it carefully and use a photo you have permission to publish.
5. Update sitemap.xml and robots.txt with your real website URL.
6. Do not claim achievements or projects that are not completed.

PUBLISHING OPTION: GITHUB PAGES
1. Create/sign in to GitHub.
2. Create a new public repository, for example charles-choga-profile.
3. Upload index.html, sitemap.xml and robots.txt to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. Wait for GitHub Pages to publish and copy the generated website URL.
7. Replace the placeholder URL in all three files with that actual URL and upload the updated files.

GOOGLE SEARCH CONSOLE
1. Open https://search.google.com/search-console/
2. Add your published website using the URL-prefix option if appropriate.
3. Complete Google's ownership verification.
4. Submit https://YOUR-REAL-SITE/sitemap.xml
5. Use URL Inspection to inspect your homepage and request indexing.
6. Check back later. Google may take time to crawl and index a new site; indexing and ranking are not guaranteed.

IMPORTANT
- Google Search Console does not guarantee a particular ranking or a Knowledge Panel.
- Do not pay anyone promising guaranteed first-page placement.
- Keep your public details accurate and consistent.
- Review the page from a logged-out browser to confirm what visitors can see.
